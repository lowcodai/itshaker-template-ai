# Prompts

Place the project's versioned prompts here.

## Naming convention
`<domain>-<action>-v<version>.md`

Example: `rag-summarize-v1.md`

## Required metadata
```yaml
---
version: "1.0.0"
author: "<your-github-handle>"
purpose: "Short description of the prompt's purpose"
model: "gpt-4o | claude-3-5-sonnet | ..."
reviewed: false
---
```
